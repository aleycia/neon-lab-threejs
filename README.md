# NEON LAB — Three.js 3D Explorer

**Nama:** Aleycia Ramadhani  
**Nomor absen:** 5  
**Nama pengumpulan:** `Absen_5_Aleycia_Ramadhani`

Website interaktif Three.js dengan model robot GLB yang diunduh dari Sketchfab, kontrol orbit/zoom, auto-rotate, pilihan warna aksen, dan mode wireframe.

## Menjalankan project
1. Extract ZIP ini.
2. Buka folder project di VS Code.
3. Jalankan `index.html` dengan Live Server.
4. Koneksi internet dibutuhkan untuk memuat Three.js dari CDN.

## File penting
- `index.html` — website utama dan pemuat model menggunakan `GLTFLoader`.
- `assets/robot.glb` — file model robot Sketchfab yang diunduh.
- `assets/neon-robot.glb` — aset tambahan bawaan project.

## Kredit model
Model: **“Robot” oleh DJMaesen** di Sketchfab.  
Sumber: https://sketchfab.com/3d-models/robot-93c9ff1cac014cc382e8666c873cdd70  
Halaman model mencantumkan lisensi CC Attribution. Pertahankan atribusi kreator dan ikuti persyaratan lisensi yang ditampilkan pada halaman unduhan.

## Upload ke GitHub dan update Vercel
1. Extract ZIP ini.
2. Buka repository `https://github.com/aleycia/neon-lab-threejs`.
3. Upload/replace isi project: `index.html`, `README.md`, dan folder `assets` termasuk `assets/robot.glb`.
4. Klik **Commit changes**. Jika Vercel terhubung ke repository ini, deployment biasanya berjalan otomatis.
5. Setelah deployment selesai, buka website Vercel dan pastikan robot tampil.
